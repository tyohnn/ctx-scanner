# graphite

이 폴더는 [tyohnn](https://github.com/tyohnn/ui) 의 디자인 시스템 `graphite` 를 복사해 온 것입니다(커밋 `59137b5`, MIT. `LICENSE` 참고).
보고서의 색, 밀도, 모서리, 글꼴, 재질이 모두 여기서 나옵니다.

| 파일 | 층 | 원본과의 차이 |
|---|---|---|
| `theme.css` | 1층 색 | 없음 |
| `globals.css` | 1층 식과 재질 | 없음 |
| `tokens.css` | 2층 밀도 · 모양 · 글자 · 움직임 | 없음 |
| `components/*.css` | 3층 규칙 | 없음. 보고서가 쓰는 부품의 파일만 가져왔습니다 |
| `style.css` | 3층 배럴 | 가져온 파일만 읽도록 다시 썼습니다 |
| `DESIGN.md` | 시스템의 성격과 금지 사항 | 없음 |

⚠ 이 폴더의 값은 손으로 고치지 않습니다. 보고서만의 값은 `../report.css` 에 두고, 거기서도 색과 치수는 이 폴더의 토큰을 읽습니다.
다른 시스템으로 바꾸려면 이 폴더를 그 시스템의 `styles/` 로 갈아 끼웁니다. 부품의 TSX 는 가져오지 않았습니다. 동작은 UI SDK 가 맡고, `../components/ui.tsx` 가 UI SDK 부품에 `cn-*` 훅 클래스를 답니다.
