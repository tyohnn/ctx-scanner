# 지도 그리기

지도는 「무엇이 언제 실리는가」를 파일에서 읽어 낸 것입니다. 세션을 돌리지 않아도 나오므로 다른 스킬보다 먼저 돌립니다.

## 차례

1. 저장소 뿌리에서 지도를 만듭니다.

   ```
   node "${CLAUDE_PLUGIN_ROOT}/scripts/scan.mjs" --root .
   ```

2. 보고서를 조립합니다. 절차는 `report` 스킬에 있습니다.
3. 사용자에게는 보고서 파일의 경로와, 지도에서 가장 먼저 볼 것 세 가지만 말합니다. 나머지는 보고서가 보여 줍니다.

## 지도가 답하는 물음

| 물음 | 보고서의 어디 |
|---|---|
| 이 지시문은 언제 실리나 | 「지도」에서 노드를 누르면 검사기의 「언제 실리나」 |
| 이 소스 파일을 열면 무엇이 실리나 | 「파일」에 경로를 적는다 |
| 늘 실리는 글은 무엇으로 차 있나 | 「제안」의 맨 위 막대 |
| 잘리거나 끊긴 것이 있나 | 「제안」의 「잘리는 글」 · 「끊긴 길」 |

## 강제 수준 다섯

지도는 모든 지시문에 수준을 하나 붙입니다. 1 · 2 · 3 은 기계가 싣기 때문에 반드시 실리고, 4 · 5 는 모델이 골라야 실립니다.

| 수준 | 뜻 | 보기 |
|---|---|---|
| 1 늘 실림 | 세션이 시작되면 실린다 | 루트 CLAUDE.md, 스킬의 이름과 설명 |
| 2 조건이 맞으면 실림 | 맞는 파일을 Read · Edit · Write 로 열면 실린다 | 폴더의 CLAUDE.md, `paths` 가 있는 규칙 |
| 3 훅이 강제 | 사건이 나면 기계가 돌린다 | settings.json 의 훅 |
| 4 지시문이 가리킴 | 지시문이 이름을 불러서 모델이 따를 까닭이 있다 | CLAUDE.md 가 부르는 스킬 |
| 5 모델이 고름 | 모델이 설명만 보고 정한다 | 아무도 부르지 않는 스킬 |

## 읽을 때 조심할 것

- 수준 2 의 글은 길이 상한이 있습니다. 컨텍스트 20만 세션은 4만 자에서, 100만 세션은 15만 자에서 뒤가 잘립니다. 경고는 뜨지 않습니다.
- 지도는 「실릴 수 있는 길」이지 「실제로 실린 것」이 아닙니다. 4 · 5 가 실제로 얼마나 실리는지는 `trace` 와 `test` 스킬로 잽니다.
- 지도의 제안 가운데 「잰 사실」만 그대로 믿습니다. 「글에서 짐작」과 「재 봐야 함」은 `advise` 스킬의 절차로 확인하고 나서 권합니다.
