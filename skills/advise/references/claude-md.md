# 지시문을 쓰는 법

`CLAUDE.md` 와 `.claude/rules/` 의 규격입니다. 문장을 어느 위치에 둘지는 `layout.md` 가 정하고, 여기에는 문장의 모양과 층마다의
틀을 둡니다. 저장소가 자기 규격을 규칙으로 두었으면(`**/CLAUDE.md` 에 걸린 규칙) 그쪽을 따릅니다. 이 규격을 저장소에 들이려면
이 파일을 `.claude/rules/claude-md.md` 로 복사하고 맨 위에 아래 frontmatter 를 붙입니다.

```markdown
---
paths:
  - "**/CLAUDE.md"
  - ".claude/rules/**/*.md"
---
```

**지시문에는 코드를 읽어서는 알 수 없는 것만 둡니다.** 문장마다 두 가지를 묻습니다. 코드나 결정 문서를 읽으면 알 수 있는가,
그리고 클로드가 그것을 찾아 읽겠는가. 앞의 답이 「예」이면 그 문장은 사본이고, 코드가 바뀌어도 그대로 남아 정본과 갈라집니다.

| 문장 | 쓰는 모양 | 둘 곳 |
|---|---|---|
| 금지와 함정 | `⚠ **<하지 않는 것>.** <어기면 무엇이 깨지는지 한 문장>(<결정 문서 · 불변식 id>)` | 지시문 |
| 사람이 정한 제약 | `<제약>(YYYY-MM-DD 사용자 결정). <되돌리지 않는 이유 한 문장>` | 지시문 |
| 짐작할 수 없는 명령 | 코드 블록 한 줄에 명령 하나 | 지시문 |
| 다른 자리를 가리키는 줄 | `<언제> <경로> 를 엽니다` | 지시문 |
| 상태 기술(화면 구성 · 주소 값 · 폴더 배치 · 파일 목록) | — | 적지 않습니다. 코드가 정본입니다 |
| 결정 경위(「종전에는 … 였습니다」) | — | `docs/decisions/`. 지시문에는 제약 한 줄과 문서 경로만 남깁니다 |
| 여러 단계의 절차 | — | 스킬 |
| 용어의 뜻 | — | `.claude/rules/glossary/<도메인>.md` |

`ctxscope` 가 이 구분으로 문장을 셉니다. 상태 기술과 결정 경위가 30% 를 넘으면 `derivable:` 제안이 나옵니다.

## 층마다의 틀

틀의 머리말(제목 아래 한두 문장)은 그대로 쓰고, `<>` 만 채웁니다. 채울 것이 없는 섹션은 지웁니다.

**루트 `CLAUDE.md`** 는 모든 작업에 걸리는 것만 둡니다. 120줄 안쪽을 권합니다.

```markdown
# <저장소 이름>

<무엇이 있는 저장소인가 한 문단>

<「그 문장이 / 가는 자리 / 언제 읽히나」 표>

## 개발 과정        ← 모든 작업이 지나는 단계
## 구조 규약        ← 어기면 되돌리기 비싼 금지
## 코드 스타일      ← 도구의 기본값과 다른 것만
## 커밋
## 찾아볼 자리      ← 「무엇 / 어디」 표
```

**앱 `CLAUDE.md`** 는 색인입니다. 그 앱의 어느 파일을 열어도 전부 로드되므로 기능 하나의 설명을 두지 않습니다.

```markdown
# <앱 이름>

<누가 쓰는 앱인가 · 호스트 · 로컬 포트 한 줄>

## <이 앱만 다른 것>
- ⚠ **<앱 전체에 걸리는 금지>.** <이유>(<결정 문서>).

## 어디에 무엇이 있나
| 무엇 | 자리 | 언제 로드되나 |
|---|---|---|

## 명령어
```

**기능 폴더 `CLAUDE.md`** 는 그 폴더에서만 맞는 함정과 제약입니다. 목록이 거의 전부이고 섹션은 대개 없습니다.

```markdown
# <기능 이름>

`<폴더 경로>` 를 고칠 때 로드됩니다. 공통 규약은 `<위 층 지시문>` 에 있습니다. 무엇이 있는지는 코드가 정본이고, 여기에는
코드만 읽어서는 알 수 없는 결정과 함정만 둡니다.

- ⚠ **<어기면 사고가 나는 것>.** <이유>(<결정 문서 · 불변식 id>).
- <사람이 정한 제약>(<날짜> 사용자 결정). <되돌리지 않는 이유>.
```

**계층 규칙 `.claude/rules/<계층>.md`** 는 여러 앱에 공통인 계층 · 파일 종류의 규약입니다. `paths` 가 없으면 항상 로드되므로 반드시 적습니다.

```markdown
---
paths:
  - "<glob>"
---

# <계층 이름>

<언제 읽히나 한 줄>

- **<규약>.** <이유>
- ❌ <금지>

<여러 단계의 절차가 있으면> <언제> `.claude/skills/<이름>/SKILL.md` 를 엽니다.
```

**도메인 용어 `.claude/rules/glossary/<도메인>.md`** 는 표 하나입니다. 뜻만 적고 비즈니스 규칙은 그 도메인의 코드에 둡니다.

```markdown
| 용어 | 뜻 | 코드 이름 | 쓰지 않는 말 |
|---|---|---|---|
```
